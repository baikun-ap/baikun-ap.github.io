# bai.kun — китайский язык среди звёзд

Сайт: **https://baikun-ap.github.io**

Бесплатный курс китайского, который работает прямо в браузере (Safari на iPhone, Chrome, любой компьютер):

- уроки по учебнику 《汉语教程》(3-е изд.) 1A и стартовый курс;
- каждый урок — 8 шагов: иероглифы и порядок черт → пиньинь → тоны → аудирование → говорение с распознаванием речи → грамматика → тест → карточки;
- интервальные карточки, таблица пиньиня, справочник грамматики, словарь из 800 иероглифов, тренажёр тонов.

Прогресс хранится на устройстве; в настройках его можно сохранить в файл.

## Разработка

```
npm ci
npm run dev        # локальный сервер
npm run build      # сборка в dist/
```

Как добавить новую книгу — см. `docs/PLAN.md`. Сайт публикуется автоматически при каждом изменении ветки `main` (GitHub Actions → Pages).
