# План: главная bai.kun в стиле «ледяной мир» (по мотивам igloo.inc)

Хозяин сайта хочет главную и курс уровня https://www.igloo.inc: светлый морозный
туман, 3D-история по прокрутке, минимум слов. **Код, модели и анимации Igloo не
копируем**, делаем своё тем же подходом. Работать по одному этапу за сессию.

## Как продолжать в новой сессии

1. Ветка `claude/finding-ad-clients-wqqwud` (репозиторий baikun-ap/baikun-ap.github.io).
   Прочитай этот файл и `AGENTS.md`.
2. Сделай **следующий невыполненный этап** ниже, отметь его `[x]`, допиши заметки.
3. Проверки: `npm run build`, `node scripts/hero-check.mjs`, `node scripts/app-check.mjs`.
4. Обнови превью-артефакт (см. «Превью»), закоммить и запушь **только в рабочую ветку**.
5. **В `main` не пушить**, пока хозяин не скажет «загружай»: `main` = живой сайт.
6. Ответить хозяину по-русски, коротко: что сделано, ссылка на превью.

## Где что лежит

- `index.html`: разметка главной (логотип, плашки, 5 подписей к сценам).
- `src/landing/story.ts`: вся 3D-сцена (three.js). Прогресс истории `s` от 0 до 1:
  0–0.2 интро (линии рисуют 学), 0.2–0.31 学 из ледяных кирпичей на холме,
  0.31–0.5 взрыв и полёт сквозь камни, 0.5–0.67 кольцо из 8 сегментов (8 шагов урока),
  0.67–0.84 портал (экзамены), 0.84–1 开始 из ледяной пыли на подиуме.
  `?capture` в адресе: кадры шагаются вручную через `window.__step(dt)` (для записи видео).
- `src/landing/tex.ts`: процедурные текстуры (снег/лёд/камень, швы кирпичей, лучи).
- `src/landing/main.ts`: язык, подписи по прогрессу, эффект расшифровки (Anime.js).
- `src/landing/style.css`: туман, тёмные моно-плашки.
- Курс внутри: `src/course/ice.css` (светлая тема — морозный туман, тёмная — полярная ночь),
  `src/ice/shards.ts` (3D-кристаллы на фоне страниц курса).

## Заметки

- Записи в облачном браузере без видеокарты (SwiftShader) выглядят хуже, чем на телефоне;
  итог хозяин оценивает по превью на своём iPhone.
- Тяжёлые эффекты (GTAO и т.п.) на телефонах отключать, держать 60 fps.
