# 星汉 Xinghan — план сайта для изучения китайского

**Идея.** 星汉 (xīnghàn) — старое китайское слово «Млечный путь», буквально
«звёздная река Хань». Слово 汉 здесь то же, что в 汉语 «китайский язык». Отсюда
концепция: космический лендинг SpaceEdu (планеты, видео-фон, стеклянные кнопки)
служит входом в курс, где каждая планета — отдельный мир изучения:

| Планета | 中文 | Мир курса |
|---|---|---|
| Земля | 地球 dìqiú | Иероглифы и слова: уроки, порядок черт, словарь |
| Венера | 金星 jīnxīng | Звук: пиньинь, тоны, аудирование, произношение |
| Марс | 火星 huǒxīng | Структура: грамматика, тесты, карточки |

## Хостинг

GitHub Pages репозитория `hanzi-trainer`: публичная ссылка
`https://tmiras257-lgtm.github.io/hanzi-trainer/`, бесплатно и бессрочно, без
сервера. Всё работает в браузере (Safari/Chrome), прогресс хранится на устройстве
(IndexedDB + зеркало в localStorage, экспорт/импорт JSON).

## Структура

- `/` — лендинг (`index.html`), один файл без фреймворков, по спецификации SpaceEdu.
- `/app/` — приложение (React + Vite), маршруты в hash:
  - `#/` главная: продолжить урок, карточки к повторению, серия дней;
  - `#/course` и `#/lesson/:id` — уроки по шагам:
    1 иероглифы → 2 пиньинь → 3 тоны → 4 аудирование → 5 говорение (распознавание) →
    6 грамматика → 7 тест → 8 карточки;
  - `#/cards` — интервальные карточки (оценки «Снова / Трудно / Хорошо / Легко»);
  - `#/pinyin` — интерактивная таблица пиньиня (инициаль × финаль, 4 тона);
  - `#/tones` — тренажёр тонов с анализом высоты голоса (уже был в проекте);
  - `#/grammar` — справочник грамматических конструкций по формулам;
  - `#/hanzi` — словарь 800 частотных иероглифов с порядком черт;
  - `#/settings` — голос, скорость, экспорт/импорт.

## Идеи, взятые у лучших сервисов

| Сервис | Что берём |
|---|---|
| HelloChinese, LingoDeer | урок как цепочка коротких шагов с мгновенной обратной связью, сборка предложения из плиток |
| Anki, Hack Chinese | интервальные повторения, четыре оценки, «сколько к повторению сегодня» |
| Skritter, Hanzi Writer | анимация порядка черт и обводка пальцем |
| Pleco | карточка слова: иероглиф, пиньинь, тон цветом, перевод, разбор на компоненты |
| Chinese Grammar Wiki (AllSet) | грамматика как формулы `Подл. + 很 + Прил.` с примерами |
| Yoyo / Yabla pinyin chart | таблица пиньиня, где каждый слог можно прослушать в 4 тонах |
| Du Chinese | текст, где каждое слово кликабельно: пиньинь и перевод по нажатию |

## Контент

Уроки лежат в `src/content/` в формате JSON (схема в `src/content/schema.ts`).
До получения книг включён стартовый курс из 6 уроков (приветствие, имена,
страны, числа, семья, время). Книги пользователя добавляются как новые файлы
уроков; упражнения строятся из слов и примеров автоматически.

## Голос

- Озвучка: системный синтез речи `zh-CN` (на iPhone голос Tingting).
- Распознавание: Web Speech API (`webkitSpeechRecognition`, в Safari работает
  при включённой диктовке Siri); сравнение по иероглифам и по пиньиню.
- Тон отдельного слога: собственный анализ высоты голоса (`src/lib/pitch.ts`).

## Проверка

`npm run build`, `npm run smoke`, `npm run tone-check`, e2e-скриншоты в
Chromium для ширин 375, 430, 768, 1024, 1440 и 2560 px.

## Как добавить книгу

1. Создать `src/content/<книга>.ts` с объектом `Book` по схеме `src/content/schema.ts`.
2. Добавить его в список `BOOKS` в `src/course/data.ts`.
3. Запустить `npm run strokes` (порядок черт для новых иероглифов) и `npm run font`
   (шрифт с новыми знаками), затем `npm run build`.

Упражнения всех восьми шагов, карточки и справочник грамматики строятся из книги сами.
